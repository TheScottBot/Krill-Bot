# Discord listing

Krill Bot is private: the author adds it to servers by invite and does not
list it in Discord's App Directory. This page records what the application
asks Discord for, so the request stays limited to what the commands use.

## Identity

- Name: Krill Bot
- Description: An unofficial Discord companion for Krillion. Log daily
  results, compare server boards, and keep track of streaks. Krill Bot never
  contacts krillion.io.

The name and text must not suggest that Krill Bot is Krillion's own.

## Permissions

| Permission | Why |
|---|---|
| Send Messages | the daily post |
| Embed Links | the daily post and every board is an embed |
| Send Messages in Threads | the daily post may be set up in a thread |

Command replies are interaction responses and need none of these. The
permission integer is 274877925376.

The author adds Krill Bot to each server directly, so no invite link is
published.

## Intents

Default intents only. Krill Bot does not request the message content,
members or presence intents.
